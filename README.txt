Présentation
Réalisation des interfaces permettant aux utilisateurs de découvrir la plateforme, de créer un compte et de se connecter pour accéder aux missions solidaires.

Fonctionnalités
Formulaire de connexion avec adresse e-mail et mot de passe.
Formulaire d'inscription avec les informations personnelles de l'utilisateur.
Navigation entre les pages de connexion et d'inscription.
Intégration d'une illustration représentant l'inclusion et la solidarité.
Mise en page adaptée à l'identité visuelle du projet.

Technologies utilisées
HTML5
CSS3
PHP


Installation et lancement
Placer le dossier du projet dans le répertoire htdocs de MAMP.
Démarrer le serveur Apache.
Ouvrir le projet dans le navigateur :
http://localhost:8888/code_arc/ptit_coup_de_pouce_personne2/index.php
